# Customer Segmentation using K-Means Clustering

## Project Overview
This project uses the K-Means Clustering algorithm to group customers into different segments based on their characteristics and spending behavior.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Finding Optimal Clusters using Elbow Method
5. Customer Segmentation using K-Means
6. Data Visualization and Insights

## Business Value
Customer segmentation helps businesses understand customer behavior, improve marketing strategies, and provide personalized services.
